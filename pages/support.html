联系前检查

  • 确认已经进入对应系统页面，并按教程完成安装、导入、更新和连接步骤。
  • 确认订阅地址没有多复制空格、换行，并且已经完整粘贴到软件里。
  • 确认客户端来自官方 GitHub Releases、App Store 或 Google Play 页面。
  • 确认系统时间正确，网络可用，并尝试更新订阅或切换其他节点。

反馈模板

  1. 设备和系统

    例如 Windows 11、macOS 14、Android 15、iOS 18，并说明手机或电脑型号。

  2. 客户端名称和版本

    例如 Clash Verge Rev、v2rayN、v2rayNG、Sing Box 或 Shadowrocket，并附上版本号。

  3. 问题现象

    说明卡在哪一步、出现了什么错误提示、是否已经尝试更新订阅或切换节点。

  4. 截图和时间

    可以提供不含订阅地址、账号密码等敏感信息的截图，并说明问题发生时间。

Launch Checklist

上线前检查

  • 替换成自己的正式域名、客服入口和 GitHub Pages 地址。
  • 定期检查 GitHub、App Store、Google Play 和教程链接是否仍可访问。
  • 确认隐私政策、使用条款、版权信息和品牌名称符合你的实际运营主体。
