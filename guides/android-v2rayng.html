v2rayNG 快速开始

适合使用 Android 手机快速导入订阅、选择节点并通过 VPN 模式连接的用户。

DownloadGitHub Releases选择 APK 安装包

快速开始

  1. 获取安装包

    从 v2rayNG 官方 GitHub Releases 下载 APK。

  2. 导入订阅

    在订阅设置中新增地址，粘贴订阅链接。

  3. 更新列表

    手动更新订阅，等待节点同步到主界面。

  4. 连接节点

    选择节点并点击连接，允许 Android VPN 请求。

下载与安装

下载 APK 后从文件管理器打开安装。部分设备会要求开启临时安装权限，安装完成后可关闭。

导入订阅

进入订阅管理，添加订阅名称和地址。更新后可按地区、倍率或延迟选择节点。

如果节点列表没有变化，先删除旧订阅缓存，再重新更新。

启动连接

点击右下角连接按钮后，系统会弹出 VPN 权限确认。连接成功后可通过状态栏图标判断运行状态。

检查与排障

  • 连接失败：换节点并检查订阅是否过期。
  • 无法更新：检查链接是否完整。
  • 网页打不开：关闭其他 VPN 应用。
  • 通知栏无图标：重新授权 VPN 权限。
