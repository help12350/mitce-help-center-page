Clash Verge Rev 快速开始

适合 Mac 用户通过图形界面管理订阅、规则模式和系统代理。

DownloadGitHub Releases选择 Apple Silicon 或 Intel 版本

快速开始

  1. 确认芯片

    在关于本机中确认 Mac 是 Apple Silicon 还是 Intel。

  2. 下载应用

    从 GitHub Releases 下载对应架构的 macOS 安装包。

  3. 导入订阅

    新增远程配置并粘贴订阅 URL，保存后更新。

  4. 开启代理

    选择节点，打开系统代理并测试网页。

下载与安装

将应用拖入 Applications 文件夹。首次打开若被系统拦截，可在隐私与安全设置中确认打开。

导入订阅

配置页面新增订阅，填写名称和链接。更新成功后在代理页选择策略组或节点。

若导入失败，检查订阅地址、系统时间和是否被旧代理设置影响。

启动连接

推荐使用规则模式。若浏览器仍无法代理，检查 macOS 网络代理设置是否被其他工具覆盖。

检查与排障

  • 打不开应用：到系统设置允许打开。
  • 无法代理：重新开关系统代理。
  • 订阅为空：重新复制订阅 URL。
  • 节点无效：更新订阅并切换节点。
