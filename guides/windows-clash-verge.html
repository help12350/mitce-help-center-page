快速开始

  2. 安装客户端

    从官方 GitHub Releases 下载最新稳定版，完成安装后启动 Clash Verge Rev。

  3. 导入配置

    选择可用节点，打开系统代理，访问常用网站确认连接状态。

下载与安装

Windows 用户通常选择 x64 安装包。若系统提示未知发布者，请先确认文件来自项目官方 Releases 页面。

导入订阅

打开配置管理区域，新增远程订阅配置。名称可以填写服务名称，URL 粘贴订阅地址。保存后点击更新，等待配置拉取完成。

如果提示下载失败，先检查订阅链接是否过期，再确认系统时间、网络和浏览器代理状态。

启动连接

在代理页面选择节点或策略组，打开系统代理。日常使用建议保持规则模式，只有需要全局代理时再切换全局模式。

检查与排障

  • 无法联网：关闭系统代理再重新开启。
  • 节点不可用：切换其他节点并更新订阅。
  • 软件无响应：退出后重新打开，必要时重启电脑。
  • 网页仍直连：确认系统代理开关和浏览器代理扩展没有冲突。
