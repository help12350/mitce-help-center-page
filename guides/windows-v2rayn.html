Windows / v2rayN

v2rayN 快速开始

适合需要轻量 Windows 客户端、订阅更新和托盘常驻管理的用户。

DownloadGitHub Releases优先选择最新正式版本

快速开始

  1. 复制订阅链接

    添加 QQ：3818898938 获取订阅地址，确认地址可以完整复制。

  2. 下载 v2rayN

    进入 GitHub Releases，选择适合 Windows 的压缩包或安装包。

  3. 添加订阅

    在订阅分组中新增地址，保存后执行更新订阅。

  4. 设置系统代理

    选择节点后启用自动配置系统代理，打开网页测试。

下载与安装

下载完成后解压到固定目录，避免放在临时文件夹。首次启动时如遇安全提示，请确认来源后再继续。

导入订阅

进入订阅设置，新增分组并粘贴订阅链接。更新后列表中会出现多个节点，可按延迟或地区筛选。

如果更新为空，先检查订阅地址是否完整，或联系 QQ：3818898938 重新获取订阅地址。

启动连接

右键托盘图标可快速切换路由模式和系统代理。常规浏览建议使用自动配置系统代理。

检查与排障

  • 节点延迟失败：先更新订阅，再切换节点测试。
  • 无法打开网页：检查系统代理是否被其他软件覆盖。
  • 订阅更新失败：确认链接没有多余字符。
  • 软件打不开：检查运行库和安全软件拦截。
