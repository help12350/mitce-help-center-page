适合需要规则模式、策略组选择和 Android VPN 模式接管流量的用户。

快速开始

  1. 下载 APK

    从官方 GitHub Releases 下载 Clash Meta Android 安装包。

  2. 允许安装

    根据系统提示临时允许浏览器或文件管理器安装应用。

  3. 导入订阅

    在配置页面新增 URL 配置，粘贴订阅链接并更新。

  4. 启动 VPN

    选择配置和节点，点击启动并允许系统 VPN 权限。

下载与安装

Android 设备可能有 arm64、armeabi-v7a 等不同架构。多数新设备可优先尝试 arm64 版本。

导入订阅

新增远程配置时填写名称和订阅 URL。配置更新成功后，进入代理页选择策略组或节点。

安装完成后建议关闭“允许未知来源安装”的临时权限。

启动连接

启动时系统会提示创建 VPN 连接，允许后应用会在状态栏显示运行状态。需要断开时回到应用内停止。

检查与排障

  • 无法安装：确认 APK 架构和系统版本。
  • 无法更新：检查订阅链接和时间设置。
  • 无法连接：切换节点并重新启动 VPN。
  • 耗电异常：不用时手动停止连接。
